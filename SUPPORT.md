# Support

## Getting Help

- **Bug?** [Open a bug report](https://github.com/avalonreset/legends-hyperyap/issues/new?template=bug_report.yml)
- **Feature idea?** [Open a feature request](https://github.com/avalonreset/legends-hyperyap/issues/new?template=feature_request.yml)
- **Build issues?** Check the [Contributing guide](CONTRIBUTING.md) for development setup

## Before Opening an Issue

1. Search [existing issues](https://github.com/avalonreset/legends-hyperyap/issues) to avoid duplicates
2. Include your legends-hyperyap version, OS, and steps to reproduce
3. For voice engine issues, include your microphone model and audio settings

## Component-Specific Help

| Component | Where to Report |
|-----------|----------------|
| legends-hyperyap voice engine | [This repo](https://github.com/avalonreset/legends-hyperyap/issues) |

## Security Issues

Do **not** open a public issue for security vulnerabilities. See [SECURITY.md](SECURITY.md) for responsible disclosure instructions.
